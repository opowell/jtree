## jtree
A toolbox for running economics experiments. Download the archive for your computer, unpack it, and run the launcher in the unpacked folder. Node.js is included; nothing needs installing.

| Download | Then run |
| --- | --- |
| <a href='https://github.com/opowell/jtree/releases/latest/download/jtree-win-x64.zip'>Windows</a> | `start.cmd` |
| <a href='https://github.com/opowell/jtree/releases/latest/download/jtree-darwin-arm64.tar.gz'>macOS, Apple Silicon (M1 and later)</a> | `start.command` |
| <a href='https://github.com/opowell/jtree/releases/latest/download/jtree-darwin-x64.tar.gz'>macOS, Intel</a> | `start.command` |
| <a href='https://github.com/opowell/jtree/releases/latest/download/jtree-linux-x64.tar.gz'>Linux, x86-64</a> | `start.sh` |
| <a href='https://github.com/opowell/jtree/releases/latest/download/jtree-linux-arm64.tar.gz'>Linux, ARM64</a> | `start.sh` |
| <a href='https://github.com/opowell/jtree/releases/latest/download/jtree-portable.zip'>Any system with Node.js 22+</a> | `start.sh` or `start.cmd` |

The admin page opens in your browser, at http://localhost:3000/admin/. On macOS, the first time, right-click `start.command`, choose Open, and confirm. Older versions (0.8.7 and before) are on the [releases page](https://github.com/opowell/jtree/releases).

#### Features
- participants only need a browser; the server runs on Windows, macOS and Linux.
- apps in Javascript, with an app editor in the admin.
- runs z-Tree treatments and oTree apps as they are, edits them as z-Tree and oTree Studio do, and converts them to jtree apps.
- three admin interfaces: jtree's own, one laid out after z-Tree, and one after oTree's.
- autoplay and bots for testing.
- rooms: permanent links for participants.
- queues: sequences of apps, with their options, for re-use.
