## jtree

<a href='https://opowell.github.io/jtree'>opowell.github.io/jtree</a>

A toolbox for running economics experiments.

#### Features
- easy to start: download, unpack and run. Node.js is included; the server runs on Windows, macOS and Linux.
- easy to access: participants only need a browser, on a laptop, desktop, tablet or phone.
- easy to program: apps are written in Javascript, and edited in the admin's app editor or any text editor.
- runs z-Tree treatments and oTree apps as they are, edits them as z-Tree and oTree Studio do, and converts them to jtree apps.
- three admin interfaces: jtree's own, one laid out after z-Tree, and one after oTree's.
- autoplay and bots for testing; rooms for permanent participant links; queues of apps and their options for re-use.
